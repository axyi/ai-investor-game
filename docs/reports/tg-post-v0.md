🎮 ai-investor-game v0 — консольная игра «продай стартап ИИ-инвестору»

Условия: спека 90 КБ (≈ 22,6k токенов), исполнитель — Claude Sonnet 5.5 в Claude Code. Весь код пишут подагенты по брифам-файлам, один промпт = один коммит, ревью в чистом контексте, `.env` не читается.

Результат: Python 3.14, решения инвестора принимает модель Laya (CPU), цифры считает код, чат-LLM (OpenRouter, gemini-3.8-flash) только озвучивает и предлагает реплики. 75 тестов, гейты 1–4 зелёные, живой прогон на реальных весах прошёл с первого раза — и до, и после ревью.

Метрики:
• промптов: 14 (+1 на спеку)
• first-run: нет — T1 упёрся в противоречие внутри спеки (ruff форматировал python-блоки в самой спеке), оператор выпустил erratum
• багов: 5 найдено / 5 исправлено (ревью: 2 нарушения буквы спеки и 2 пробела в тестах; 5 замечаний отклонены с причинами)
• токены: подагенты ≈ 1,1M записи в кэш + 20,9M чтения, output харнесс не отдаёт (≥ 17k); основной контекст ≈ 200k
• стоимость: подписка; по публичным ценам ≈ $7 (подагенты, нижняя оценка) + ≈ $0,02 чат-LLM
• время: ≈ 2 ч
