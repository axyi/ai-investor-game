Evidence: per-request `usage` fields of the lab session's local Claude Code transcripts
(main session and its `subagents/` files), aggregated by `tools/session-usage.py` of the lab
repo; Codex usage lines (`finish=stop`, prompt / completion / reasoning tokens) returned by
each cross-review round.

Rows 2–15: per-request `usage` fields of the ten subagent transcripts of this run (the session's `tasks/*.output` files), aggregated by a small script that sums only the numeric counters, deduplicated by request id; `uncached` = `input_tokens`, `cache write` = `cache_creation_input_tokens`, `cache read` = `cache_read_input_tokens`. The transcripts keep `output_tokens` at its stream-start value (T1: 375 over 31 requests), so output is `unknown` and the floor (17,145 over all rows) is only a floor. The "harness total" is the combined `subagent_tokens` figure the Agent tool returned, without an in/out split. Public-API prices: OpenRouter's model list of 2026-10-01 (`anthropic/claude-sonnet-5.5`: $2 in / $10 out / $0.20 cache read / $2.50 cache write per MTok; `google/gemini-3.8-flash`: $0.75 in / $3.75 out). The chat-LLM figure assumes ~2k tokens in and ~0.4k out per request over 7 requests (1 T0 probe + 3 + 3 live-run calls); the game logs no usage.
